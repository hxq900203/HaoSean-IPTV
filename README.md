## 这是怎么工作的？

GitHub 每天北京时间早上 6 点左右会自动：

1. 从 [iptv-org](https://github.com/iptv-org/iptv)（整理全球**公开免费**电视源的项目）下载最新的频道列表
2. 一个个试播，把看不了的去掉
3. 生成新的播放列表 `haosean.m3u`

**你什么都不用做**，App 每次刷新都会读到最新的列表。

## 频道分组

| 分组 | 内容 |
| :-- | :-- |
| 中国大陆 | 检测能看的央视、卫视等 |
| 港澳台 | 检测能看的香港、澳门、台湾频道 |
| 国际新闻 | 检测能看的各国新闻频道 |
| 中国大陆（备用） | 在海外没测通的国内频道，**你在国内很多其实能看** |

> 为什么有「备用」？检测是在 GitHub 的海外服务器上做的，有些国内频道只允许国内访问，在海外测不通，但你在国内能看。

## 文件说明

| 文件 | 是什么 |
| :-- | :-- |
| `haosean.m3u` | **专属播放列表**：能看的频道 + 国内备用（**用这个**） |
| `all.m3u` | 全部频道，包括没检测通过的 |
| `stats.md` | 每个分组能看几个、更新时间 |
| `fetch.py` | 自动抓取程序（每一步都有中文解释） |

前三个是程序自动生成的，不用手动改。

## 会不会哪天突然停了？

已经做了这些保险：

- **保活**：GitHub 规定仓库 60 天没动静会停掉定时任务，每次运行都会自动重置这个计时
- **网络出问题时不会清空列表**：抓取失败就保留上一次能用的列表
- **失败自动重试**：下载失败会自动再试几次

## 手动更新（想立刻刷新时用）

1. 点上方的 **Actions**
2. 左边选「**更新直播源**」
3. 点右边的 **Run workflow** → 再点绿色的 **Run workflow**
4. 等一两分钟，出现绿色 ✅ 就好了
